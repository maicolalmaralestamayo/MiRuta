# Definición de Listo (*Definition of Ready*)

Una historia puede entrar en un sprint solo cuando:

- [ ] Está escrita como *Como [rol] quiero [acción] para [beneficio]*.
- [ ] Tiene criterios de aceptación claros y comprobables.
- [ ] El Product Owner resolvió las dudas de negocio y las reglas están en `docs/02-procesos.md`.
- [ ] Están identificadas las tablas, los recursos de la API y las pantallas que toca.
- [ ] Está estimada en puntos y cabe en un sprint (8 puntos como máximo; si es mayor, se divide).
- [ ] Sus dependencias ya están hechas o entran en el mismo sprint.
